Code complexity is not one number. The ecosystem keeps independent questions independent:

- **Big-O** describes supported asymptotic growth as input changes.
- **Cyclomatic complexity** counts structural decision paths.
- **Cognitive complexity** estimates comprehension burden under this project's documented C# convention.
- **Nesting depth** captures the deepest supported control-flow nesting.
- **Size and Halstead metrics** describe code volume and operator/operand vocabulary; they are not Big-O.

Start with [complexity models](./complexity-models/), then study [operations, recursion, and Unknown](./operations-recursion-unknown/). The detailed [cognitive complexity](./cognitive-complexity/) and [Halstead](./halstead-metrics/) pages are synchronized from the repository's technical documentation.
