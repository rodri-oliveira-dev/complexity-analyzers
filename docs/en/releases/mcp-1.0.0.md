# ComplexityAnalysis.Mcp 1.0.0

The first stable release of `ComplexityAnalysis.Mcp` makes the repository's
deterministic C# complexity analysis available to compatible local agents as an
independently installed .NET 10 tool.

## Highlights

- Install `ComplexityAnalysis.Mcp` and run the `complexity-mcp` command without
  a repository checkout or separate CLI installation.
- Analyze `.csproj`, `.sln`, and `.slnx` inputs, query exact member evidence by
  StableId, and compare deterministic complexity snapshots through three
  read-only MCP tools.
- Choose the backward-compatible full response or an explicitly bounded summary
  response for lower context usage.
- Reuse an exact analyzed snapshot through `analysisId`, avoiding duplicate
  analysis without treating cached data as current filesystem state.
- Preserve conservative `Unknown` results and typed evidence; comparisons never
  convert inconclusive estimates into proven regressions.
- Enforce an allowed root, extension checks, symbolic-link/reparse-point
  protection, per-request file/byte limits, timeout, cancellation, and strict
  stdout/stderr separation.
- Configure the installed command with VS Code / GitHub Copilot, Codex, and
  Claude Desktop using documented local stdio formats.

## Install

```bash
dotnet tool install --global ComplexityAnalysis.Mcp --version 1.0.0
complexity-mcp --root /absolute/path/to/project
```

This release requires the .NET 10 runtime. The server is local, stdio-only, and
read-only. It does not provide HTTP transport, network access, telemetry, shell
execution, or source mutation.

Release artifacts include the NuGet package and its SPDX 2.3 SBOM. GitHub build
provenance and SBOM attestations are generated by the protected release
workflow.
